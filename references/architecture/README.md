# Architecture Notes

This folder stores curated, human-written references.

- `monarch.md`: Go开发的http服务器, 处理http请求.
- `gizmos.md`: Go开发的一些cli工具.
- `torrid.md`: flutter开发的自用的安卓移动应用, 有一些http请求需要'monarch'项目处理.
- `northstar.md`: flutter开发的windows端桌面应用, 主要进行图形化地操作Go程序比如http服务器的启动与暂停, 各cli程序的启动与监控输出等.

Guidelines:

- Keep this folder hand-maintained.
