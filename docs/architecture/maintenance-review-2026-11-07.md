# 三端维护与验收 · 2026-11-07

## 架构取舍

保留 Go 真源、Flutter 本地体验、Vue 同源运维的边界。Riverpod、Dio、Hive 与现有功能目录可以继续维护；当前规模无需增加 Gradle 子模块、状态管理框架、消息队列或独立运维服务。关键回归用例与架构说明另外维护。

## 已落实

- Android：首页保持点击背景展开左侧菜单的交互，保留个性化背景与座右铭。返回键先关闭菜单，关闭时菜单不接收触摸；媒体入口去掉叠加边距，图标对应内容，并支持大字体单列。
- Backend：漫画写任务按提交顺序排队，排队可以立即取消，初始化与删除不能插队。业务失败保留结果并显示失败。任务结束即裁剪历史，日志与结构化输出均设字节上限。
- Backend：AI worker 使用退避定时器，暂停时停止检查队列；侧车、Ollama 与索引共用资源回收循环，无任务时不启动模型进程。
- Ops：保留侧栏导航，工作台聚焦状态；任务中心统一查看结果、日志和取消操作，切换维护标签保留任务与参数。高级参数与漫画运行环境默认折叠，下载操作优先展示。打卡样式独立编辑，撤销输入与放弃样式经确认。
- 双端编辑：网页走独立的条件写入接口，事务内校验编辑快照；冲突整批拒绝并回滚附件，保留输入与随笔草稿。打卡刷新保留旧表单和样式快照，切页及切日期提醒未保存内容。重连失败不卸载正在编辑的页面。

## 数据与交付边界

本轮没有修改数据库结构，没有迁移或写入生产数据库，也没有改动媒体、附件、密钥和 agent 指令文件。验收使用独立 SQLite 与媒体目录。后端与 Gallery CLI 已重新构建；生产实例未启动。启用新版时后端与网页应配套更新，旧后端会拒绝新的网页编辑接口。

手机离线同步仍使用既有 sync_version=2 的逐行时间戳合并及 tombstone，不引入版本历史。编辑同一条记录前先同步手机；设备时钟应准确。在线快照以模块为单位，另一条同模块记录的更新也会要求核对后重新编辑，这是个人场景下保守且简单的取舍。
