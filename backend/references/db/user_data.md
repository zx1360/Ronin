# 用户数据

建表真源为 [sqlite.sql](sqlite.sql)。版本、游标、在线编辑和时迹备份见[跨端契约](../../data/contracts/README.md)。

- 随笔维护建档日期与创建时间。留言的 `timestamp` 用于显示，编辑可带 `updated_at` 并推进随笔版本。隐藏标签子树排除于回顾统计和抽样，Android 会补充本机隐藏随笔 ID。
- 打卡日期是日历日，`booklet_records` 对 `(style_id, date)` 唯一。标签计数、年度汇总和打卡统计由数据派生，统计重算保留业务行版本。
- `user_data_changes` 保留每行最新变动和删除标记。revision 独立于设备时间，支持离线记录补传。版本时间超前服务端五分钟以上时拒绝写入。
- 图片使用不可变文件名。偏好上传支持清理不再引用的偏好图片，业务记录合并保留附件。草稿独立于正式记录。
