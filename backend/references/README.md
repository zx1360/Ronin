# References

This directory contains generated and curated reference artifacts for cross-workspace development.

## Single Source of Truth

- Source of truth: Go server handlers, models, router, and CLI entrypoints.
- Generated references: derived from source code by script.
- Consumer (e.g. Flutter): read references only; do not hand-edit generated outputs.

## Structure

- `api/openapi/`: OpenAPI artifacts generated by `swag` (`swagger.json`, `swagger.yaml`).
- `api/routes.json`: machine-friendly route snapshot exported from live Gin router registration.
- `api/routes.md`: human-readable route table.
- `cli/*.md`: CLI `-h` snapshots for active commands.
- `architecture/`: curated high-level notes for backend/frontend collaboration.
- `scripts/generate_refs.ps1`: one-command generator.

## Usage

Run from repository root:

```powershell
powershell -ExecutionPolicy Bypass -File .\references\scripts\generate_refs.ps1
```

## Update Discipline

- When API/CLI behavior changes, regenerate references in the same commit.
- Keep generated files versioned in git so other workspaces can consume them directly.
