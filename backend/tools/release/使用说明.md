# Ronin Windows x64

1. 解压到自己有写权限的文件夹，双击 `Start Ronin.cmd`。窗口保持打开即为运行，按 Ctrl+C 结束。
2. 在电脑上访问 http://127.0.0.1:7275/ops/。首次启动生成数据库、HTTPS 证书和 API 密钥。
3. 安装 Torrid APK，手机和电脑连同一局域网。按 Northstar「设置 → 连接」配置手机。需要 Windows 防火墙许可时，只在自己的专用网络放行 Monarch。
4. 把媒体放入 `backend/gallery/Raw`，在 Northstar「任务」运行 Gallery 摄入。视频处理需要 PATH 中的 FFmpeg 和 FFprobe。

## 可选能力

| 能力 | 部署与切换 |
| --- | --- |
| 感知去重 `phash` | 内置于 Monarch，基础包开箱可用。 |
| 语义搜索 `embed` | 运行 `pwsh -File backend/tools/ai/install.ps1` 安装侧车和多语 SigLIP 2。视觉塔、文本塔和分词器应成套替换。更换后停止服务再替换文件，并在 Ops 重生成向量。 |
| 人脸 `face` | 基础包和默认安装均省略权重。在有使用授权时，将现有侧车支持的检测与识别模型放入 `backend/tools/ai/models/buffalo_l`。换权重后重生成并重聚类，先备份已有的人物整理数据。[InsightFace 模型许可](https://github.com/deepinsight/insightface#license) |
| OCR `ocr` | 随 RapidOCR Python 依赖安装，使用其配套权重。 |
| 图像标注与对话 `vlm` | 自备 Ollama 和支持图像的模型。已有 Ollama 可直接复用，也可在 `backend/.env` 设置 `OLLAMA_EXE` 和 `OLLAMA_MODELS`，由 Monarch 按需拉起和回收。模型在 Ops 的 AI 页选择，可先试 [Qwen3-VL 4B](https://ollama.com/library/qwen3-vl:4b)。[Ollama Windows 独立 CLI](https://docs.ollama.com/windows#standalone-cli) |

侧车需要安装可用的 64 位 Python。安装后刷新 Ops 的 AI 依赖状态，按需排队或调整自动处理能力。此包默认只自动入队去重，队列初次启动为暂停。

漫画下载可另建 Python 环境，安装 `backend/gizmos/comix/requirements.txt` 及 Playwright Chromium，再在 `backend/.env` 将 `COMIX_PYTHON` 指向该解释器并重启。可在 Ops 的漫画页初始化和查看状态。

更新前退出 Monarch，备份自己的数据目录及配置。保留 `backend/data`、`backend/gallery`、`backend/static`、`backend/cert` 和 `backend/.env`，再更新程序和资源。
