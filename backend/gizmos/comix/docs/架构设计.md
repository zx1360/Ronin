# comix 架构

Torrid 和 Northstar 通过 Monarch 访问书库。Monarch 直接读写共享 SQLite，并用任务引擎托管下载等 Python 子进程。

| 入口 | 职责 |
| --- | --- |
| [Go 调用层](../../../internal/service/comix/) | 命令参数、环境变量、JSON 解析和任务状态。 |
| [Python CLI](../comix/cli.py) | 解析参数并包装[命令结果](协议文档.md)。 |
| [调度](../comix/scheduler.py) 与 [SQLite](../comix/db.py) | 搜索选源、章节登记、下载、追更与清理。 |
| [适配器](../comix/adapters/AGENTS.md) | 站点搜索、详情和图片 URL。 |

存储见[漫画数据](../../../references/db/comix.md)，并发和落盘规则见 [comix 指引](../AGENTS.md)。
