# 项目组成及技术细节

单仓库三端：`backend/`（Go 后端 Monarch）+ `frontend/`（Flutter 安卓端）+ `ops/`（运维网页端）。
各端的约定见对应目录下的 AGENTS.md，根目录 `.github/copilot-instructions.md` 是入口索引。

## 后端(Go)

> **1. http服务器, 用以支持网络请求.**
>
> **2. 一些CLI命令工具, 用以进行资源的批量处理.**

### 一、高性能 无感知后台运行

由于使用Go编写, 相比java/python开发的http服务器占用内存少, 响应高效, 后台友好.

可以编写vbs脚本放入开机启动目录以无窗口模式静默运行, 平时几乎不占用性能损耗

### 二、应用干净

一体式以独立目录存在, 所有数据均不存入C盘的文档目录之类的, 仅存于所在的目录中, 可方便地彻底删除.

**==因此, 应当自行做好数据的管理防止丢失数据==**

## 数据库(SQLite)

> 单文件 SQLite，置于 `backend/data/monarch.db`，**不依赖任何外部数据库服务**。

备份与迁移就是拷贝这一个文件（连同 `-wal` 附属文件）。原 PostgreSQL 数据已完成一次性迁入
（迁移工具归档在仓库外的 `Ronin-archive/`），原库可原样保留作为回滚。

## ops 网页端

> 运维管理界面，纯静态 HTML/CSS/ES 模块，由后端内置于 `/ops` 提供。

启动 Monarch 后打开 `http://127.0.0.1:<LOCAL_DEBUG_PORT>/ops/`。页面本身不具备本机权限，
进程与任务生命周期、路径定位、配置读写都由后端经回环 http 提供，页面与这些接口都只对本机开放。

## 前端应用(Flutter)

> 仅安卓移动端一套代码（仓库里没有其它平台目录，代码里也没有平台分支）。

### 一、数据安全

**隐私**

**所有用户数据存于本地不上云, 不会被外部获取**

**备份**

可通过部署本项目的backend部分运行http服务器, 实现备份到pc上.

### 二、应用干净

卸载应用即删除所有数据不留痕. 不保留任何配置信息和数据.

**==因此, 未备份的数据会在应用卸载后真正消失.==**

- 打卡/随笔等数据保存于内部应用私有目录
- 相应的图片等文件保存于外部应用私有目录
- 后端连接配置存于轻量键值（SharedPreferences）

PS: 除了某些页面手动点击"保存"按钮后, 保存在外部公共空间. (为了保存的图片能够被手机自带的相册识别到).

### 三、后台友好

**CPU友好:** 只有用户操作才会进行相应的操作.

处于后台时不会运行其他行为. (指仍旧活跃的后台代码)

**内存友好: **

不知道, 感觉应该不占内存.

# 关于本项目

## 一、开源

[zx1360/Ronin: 个人资源管理pc后端+多功能安卓软件.](https://github.com/zx1360/Ronin)

业务闭环联系紧密, 所以合并成一个仓库:

- [zx1360/monarch](https://github.com/zx1360/monarch): Go 后端与 CLI。
- [zx1360/Torrid](https://github.com/zx1360/Torrid): 安卓端自用多功能软件（打卡、随笔、漫画、画廊等）。
- 运维端原为 Northstar 桌面应用，现由本仓库的 `ops/` 网页端承担。

## 二、业务闭环

原始数据初处理、索引、后端维护、客户端消费并反馈. 

本项目分为三端, 个人用户可自行部署完整实现所有功能.

## 三、数据隐私与安全

后端与前端应用、ops 网页端的网络交互通过 https 协议实现, 并通过 x-api-key 再套层验证.
ops 网页端走**仅本机回环**的 http（浏览器无法静默信任自签证书），本机能力接口一律限定回环来源.

> 不过需要注意的是, 自部署需自行生成自签证书或申请权威证书.
